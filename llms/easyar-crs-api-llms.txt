# EasyAR CRS (Cloud Recognition Service)

> Cloud image-recognition web service by VisionStar Information Technology (Shanghai) Co., Ltd.
> Manage up to 100,000 image targets per cloud database and recognize them from camera frames in
> ~0.1s. Two channels per image-library instance: a Server-end URL (target management, HTTPS :443)
> and a Client-end URL (image recognition, HTTPS :8443, host shaped like
> <your-domain>-cn1.crs.easyar.com). Data centers: China-Shanghai and US-Silicon Valley.
> Generated by API Evangelist from EasyAR's published documentation (no provider llms.txt exists).

## API operations

- POST /targets: create image target (base64 JPG/PNG, max 2MB; name, size, meta, active, allowSimilar)
- GET /targets/infos: list targets (pageNum, pageSize <= 100)
- GET /target/<target_id>: get one target
- PUT /target/<target_id>: modify target attributes
- DELETE /target/<target_id>: delete target
- POST /grade/detection | /grade/tracking | /grade/detail: image recognizability rating (0-4, -1 invalid)
- POST /similar: check for similar targets before creating
- POST /v2/search: recognize an image (multipart/form-data, Client-end URL :8443)
- GET /ping: health check (no auth)

## Authentication

- Token auth: Authorization header carries an STS-issued temporary token (create via developer center or by signing apiKey+expires+acl+timestamp with the API Secret against https://uac.easyar.com/token/v2)
- Signature auth: appId, timestamp, apiKey, signature request parameters (hex sha256 of sorted key+value pairs + API Secret)
- Never embed API Key/Secret in client apps; generate tokens server-side
