# EasyAR CRS API

EasyAR CRS (Cloud Recognition Service) is a cloud image-recognition solution that lets developers manage up to 100K image-targets online and recognize them from camera key-frames. It provides HTTP web-service APIs for target management and recognition, with request-signing/token authentication on per-instance regional base URLs.

## APIs

- **EasyAR CRS Web Service API** — REST/HTTP API for cloud image recognition: target management endpoints (/targets/, /target/<id>, /grade/detection/, /ping) and a recognition endpoint (/search), plus a token exchange service. Uses per-instance, per-region base URLs issued when a CRS App Instance is created. (`https://uac.easyar.com/token/v2`)

> Confirmed conventional REST/HTTP API for CRS with documented target-management and recognition endpoints and token/signing auth. Access requires registering at https://portal.easyar.com/ and creating a CRS App Instance to obtain API Key/Secret and AppId.
